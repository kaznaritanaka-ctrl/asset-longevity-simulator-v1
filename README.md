# 資産寿命シミュレータ

FIRE 前の形成期と FIRE 後の取り崩し期で異なる資産配分を設定し、年次モンテカルロ計算で資産寿命を確認する Web アプリです。結果は資産枯渇だけでなく、ユーザーが指定した条件への抵触も「計画未達」として判定できます。

## 主な機能

- 形成期・取り崩し期ごとの資産配分とプリセット
- 積立、支出、年金、売却実効税率、名目／実質リターンの設定
- 年齢別の未達経路と代表シナリオの確認
- シミュレーションの 95% 推定区間、運用だけの最大下落、入出金込みの残高減少の分離表示
- URL フラグメントによる条件共有（共有先で保存済みの設定を自動上書きしません）

## 計算モデルの前提

- 資産クラスごとの算術平均リターンと年率ボラティリティ、相関行列から、相関付き正規乱数で年次リターンを生成します。
- 年 1 回リバランスし、FIRE 年齢の前後で配分を切り替えます。
- 「実質リターン」選択時は、積立・支出・年金・結果金額をすべて現在の購買力で扱い、インフレ率を重ねて適用しません。
- 税率は収益の厳密な課税所得計算ではなく、売却額に対する実効税負担率です。
- 本ツールは将来の成果を保証するものではなく、投資・税務・法務上の助言ではありません。

## データ出典と注意

参照日: 2026-09-06

- 株式・国債・手形、CPI、対ドル為替: [Jordà–Schularick–Taylor Macrohistory Database R6](https://www.macrohistory.net/database/)
- リターン系列の論文: Òscar Jordà, Katharina Knoll, Dmitry Kuvshinov, Moritz Schularick, Alan M. Taylor, “The Rate of Return on Everything, 1870–2015,” *Quarterly Journal of Economics* 134(3), 2019.
- 1960–2020 年のドル建て金価格: [World Bank Commodity Price Data (The Pink Sheet)](https://www.worldbank.org/en/research/commodity-markets)

JST データは CC BY-NC-SA 4.0 の条件で提供されており、帰属表示、非営利利用、同一条件での共有が求められます。詳細は上記データベースの利用条件を確認してください。

重要: World Bank Pink Sheet の公式長期系列は 1960 年以降です。現行コードの「最長（1886–2020）」と「戦後（1952–2020）」に含まれる 1960 年以前の金統計は、接続元データと再生成手順がこのリポジトリに同梱されていないため、検証中の参考値です。
